API Documentation

REST API layer untuk Toko Era Digital. Dibangun sebagai Vercel serverless functions, validasi JWT, dan service role key di server-side.

🔐 Authentication

Semua endpoint /api/admin/* dan /api/me memerlukan Bearer token (Supabase access token) yang didapat setelah login. 

# Contoh request dengan auth
curl https://your-domain.vercel.app/api/admin/stats \
  -H "Authorization: Bearer <SUPABASE_ACCESS_TOKEN>"
⚠️ SUPABASE_SERVICE_ROLE_KEY hanya dipakai di server (di dalam /api/*.js). Jangan pernah expose ke browser atau commit ke git.

📋 Public Endpoints

GET /api/health

Health check — verifikasi Supabase env vars sudah dikonfigurasi. Tidak butuh auth.

# Contoh response
{
  "status": "ok",
  "service": "toko-era-digital-api",
  "timestamp": "2026-08-13T09:00:00.000Z",
  "env": { "SUPABASE_URL": true, "SUPABASE_ANON_KEY": true, "SUPABASE_SERVICE_ROLE_KEY": true }
}

👤 User Endpoints

GET /api/me

Mengembalikan profil user yang sedang login berdasarkan Bearer token, beserta info store jika user adalah Sobat Era Digital.

curl https://your-domain.vercel.app/api/me \
  -H "Authorization: Bearer <token>"

🛡️ Admin Endpoints

Semua endpoint di bawah ini memerlukan admin role. Server akan memverifikasi JWT dan cek profiles.role = 'admin' sebelum memproses request.

GET /api/admin/stats

Dashboard stats: jumlah users, codes, products, stores, dan banned users.

GET /api/admin/users?role=&banned=&q=&limit=

Daftar semua profiles. Filter opsional: ?role=mitra (default Sobat Era Digital), ?banned=true, ?q=keyword.

GET POST DELETE /api/admin/products

CRUD produk etalase. POST body: { name, price, category?, stock?, description?, is_active? }. DELETE: ?id=<uuid>.

# Create product
curl -X POST https://your-domain.vercel.app/api/admin/products \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"name":"Kaos Distro","price":150000,"category":"Pakaian","stock":100}'
GET POST DELETE /api/admin/codes

CRUD kode pendaftaran. POST body: { count?: 1, prefix?: "TED", expires_at?: "ISO" }. DELETE: ?id=<uuid>.

# Generate 5 codes
curl -X POST https://your-domain.vercel.app/api/admin/codes \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"count":5}'
POST /api/admin/ban

Ban/unban user. Body: { userId, banned }. Tidak bisa ban admin lain atau diri sendiri.

POST /api/admin/reset-password

Reset password user lain via Auth Admin API. Body: { userId, newPassword? }. Jika newPassword kosong, server generate password aman 16 karakter.

# Reset password (auto-generated)
curl -X POST https://your-domain.vercel.app/api/admin/reset-password \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"userId":"uuid-here"}'

# Response
{
  "success": true,
  "target": { "id": "uuid", "email": "user@example.com" },
  "generated": true,
  "temporaryPassword": "aB3!xY9#kLm7pQr$",
  "performedBy": "admin@example.com"
}
